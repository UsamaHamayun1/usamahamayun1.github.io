Passive RF drone detection — Remote ID at multi-kilometre range

Dual-receiver system that passively detects drone Remote ID broadcasts on Bluetooth (1M + Long Range Coded PHY) and Wi-Fi 2.4 GHz, running on Nordic nRF53 / nRF70 front-ends with edge processing on Jetson. I own the full chain: antenna selection and link budgets, receiver firmware, the MQTT ingest / detection / live-map pipeline, and the field-test methodology with GPS ground truth.

The engineering that mattered wasn't range for free — it was diagnosing an overloaded front-end and fixing it with a 6 dB pad after the LNA (a 21× recovery in packet density), and proving detection performance against a commercial reference receiver in controlled simultaneous trials. In July 2026 field trials, a single receiver station tracked three drones simultaneously — two on BLE, one on Wi-Fi — out to 4.2 km, resolving per-target identity, GPS ratio and PHY mix from 2,400+ logged packets. I also carried the qualification path toward a production receiver: Friis noise-cascade analysis of the full RF chain and module-vs-devkit trade studies, validated against the field data.

Closed-loop autonomous tram simulation — Isaac Sim ↔ ADAS stack

Simulation-in-the-loop validation for a production rail ADAS stack: a photoreal tram scene in NVIDIA Isaac Sim publishes camera and LiDAR streams over ROS 2, bridge nodes carry them over ZMQ into a 15-container perception and collision-checking stack on NVIDIA IGX, and the resulting brake verdicts are fed back to the simulated tram's physics — a true closed loop, running with zero container restarts.

Along the way: ported OpenCV with CUDA support to a Blackwell-generation GPU (sm_120) under an ABI-locked toolchain, and fixed a production serialization bug in the stack's wire protocol.

2026 Somnum Technologies
System architect

GPS-denied positioning for firefighters — architecture & PoC

System design for tracking firefighters inside burning buildings, where GNSS doesn't exist and RF behaves badly. Wearable node: STM32-based fusion MCU logging a tactical-grade and a consumer-grade IMU simultaneously, plus barometer — dead-reckoning with zero-velocity updates computed onboard so the node stays useful even if comms drop. A static edge node (Jetson Orin) anchors the absolute frame via BLE angle-of-arrival and GNSS-RTK, and runs global fusion.

Long-range telemetry on licensed 868 MHz (3 W authorization) — where the real win is duty-cycle relief, not raw power. Designed to a ≤1.5 m 3D accuracy spec with a deliberate PoC-to-product upgrade path (BLE AoA → UWB AoA).

side project

GPS tracker for Semana Santa processional floats

A tracker that publishes the live position of multi-tonne religious floats moving through crowded medieval streets. The constraint that shaped everything: the cellular module shares one RF front-end between GNSS and LTE, so the firmware runs a strict sequential fix-then-transmit cycle using the modem's native MQTT stack — no Linux networking in the loop. Small, cheap, and it worked on procession day.
